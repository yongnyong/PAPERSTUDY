# 07. π*0.6: a VLA That Learns From Experience

- **저자/소속**: Physical Intelligence, 2025.11
- **arXiv**: [2511.14759](https://arxiv.org/abs/2511.14759)
- **한 줄 요약**: 모방학습(imitation learning)으로 학습한 VLA는 시연 데이터의 품질을 절대 넘어설 수 없다는 한계를, **RECAP**(advantage-conditioned RL)이라는 기법으로 깨고, 배포 후 실제 성공/실패 경험으로부터 "시연보다 더 나은" 정책을 만드는 방법.

## 1. 문제의식

π0, π0.5를 포함해 지금까지의 VLA는 모두 **모방학습(imitation learning)** 으로 학습된다 — 사람이 시연한 (상태, 행동) 쌍을 그대로 흉내내도록 학습. 이 방식의 근본적 천장(ceiling)은 명확하다:

> **정책은 시연자보다 잘할 수 없다.** 시연 데이터에 비효율적인 동작이나 실수가 섞여 있으면 정책도 그걸 그대로 배운다. 그리고 배포 이후 로봇이 실제로 겪는 실패들(새로운 환경에서의 실수, 예상 못한 물체 배치 등)은 그 어떤 시연 데이터에도 없다 — 그래서 모방학습만으로는 "실전에서 겪은 실패로부터 배우는" 것이 원천적으로 불가능하다.

**핵심 질문**: 강화학습(RL)을 쓰면 시연을 뛰어넘을 수 있다는 건 알려져 있지만, 표준 RL(정책 그래디언트, Q-learning 등)은 flow matching처럼 복잡하고 multi-modal한 연속 action 분포를 다루는 대형 VLA에 그대로 적용하기 어렵다. **flow-matching 기반 VLA에 RL을 어떻게 붙일 것인가?**

## 2. 핵심 아이디어 — RECAP (Advantage-Conditioned Policy)

RECAP = **R**L with **E**xperience and **C**orrections via **A**dvantage-conditioned **P**olicies.

### 2.1 Advantage란?

강화학습에서 **advantage** $A(s, a)$ 는 "상태 $s$ 에서 행동 $a$ 가 평균적인 행동보다 얼마나 더 좋은가"를 나타내는 값이다:

$$
A(s, a) = Q(s, a) - V(s)
$$

- $Q(s, a)$: 상태 $s$ 에서 행동 $a$ 를 하고 그 이후 최선을 다했을 때 기대되는 누적 보상
- $V(s)$: 상태 $s$ 에서 평균적으로 기대되는 누적 보상

$A(s,a) > 0$ 이면 "그 상황에서 평균보다 나은 선택", $A(s,a) < 0$ 이면 "평균보다 나쁜 선택"이라는 뜻이다.

### 2.2 Advantage-Conditioning — RL을 "생성 조건"으로 바꾸기

RECAP의 트릭은 policy gradient처럼 파라미터를 직접 advantage 방향으로 업데이트하는 대신, **advantage 값 자체를 flow matching의 조건(condition)으로 모델에 알려주고 생성하도록 학습**시키는 것이다.

1. 오프라인 데이터(시연 + on-policy 롤아웃 + 사람의 개입/교정)로부터 가치함수 $V_\phi(s)$, $Q_\phi(s,a)$ 를 학습
2. 데이터셋의 각 $(s, a)$ 쌍에 대해 advantage $A(s,a) = Q_\phi(s,a) - V_\phi(s)$ 를 계산하고, 이를 몇 개의 구간(bin)으로 양자화해 조건 변수 $c = \text{bin}(A(s,a))$ 로 만듦
3. π0와 동일한 flow matching 손실을, advantage 조건 $c$ 를 추가로 입력받도록 확장:

$$
\mathcal{L}_{\text{RECAP}} = \mathbb{E}_{\tau,\, \epsilon,\, (s,a) \sim \mathcal{D}}\left[\left\| v_\theta\big(a^\tau, \tau, z(s), c\big) - (a - \epsilon) \right\|^2\right], \quad c = \text{bin}\big(A(s,a)\big)
$$

4. **추론(inference) 시**: 항상 "가장 좋은" advantage 구간 $c = c_{\text{high}}$ 를 조건으로 넣어 action을 생성 — 즉 "데이터셋에서 advantage가 높았던 행동들과 비슷한 행동을 생성하라"고 모델에 지시하는 것과 같다.

이 방식이 영리한 이유: **표준 RL이 요구하는 복잡한 수학적 장치(정책 그래디언트의 분산 감소 트릭, importance sampling 등)가 전혀 필요 없다.** 그냥 "가치가 높은 행동/낮은 행동"을 구분하도록 생성 모델을 조건화하고, 테스트 시 "높은 가치"를 요청하기만 하면 된다. 이 덕분에 discrete/simple continuous action space에 국한되던 기존 방법과 달리, flow matching이 만드는 복잡하고 multi-modal한 action 분포에도 그대로 적용 가능하다.

### 2.3 아키텍처

- 백본: **5B 파라미터 VLM** + flow-matching action expert (π0 계열과 같은 dual-expert 구조 계승)
- 학습 레시피(**"KI" recipe**): (1) 다양한 데이터 소스에 대한 next-token prediction으로 사전학습, (2) flow-matching action expert를 **stop-gradient**로 붙여 학습 — action expert의 그래디언트가 VLM 백본으로 역전파되지 않게 막아, 이질적인 RL 학습 신호가 사전학습된 VLM 표현을 망가뜨리지 않도록 안정화

### 2.4 학습에 쓰이는 "경험" 데이터의 종류

RECAP은 세 종류의 이질적 데이터를 하나의 파이프라인에 통합한다:

- **시연(demonstration)**: 기존 모방학습 데이터
- **On-policy 롤아웃**: 현재 정책이 실제로 실행한 궤적(성공/실패 모두 포함)
- **전문가 개입(teleoperated intervention)**: 로봇이 자율적으로 작업을 수행하는 도중 사람이 개입해 교정한 데이터 — "실패로 이어질 뻔한 순간에 사람이 어떻게 바로잡았는가"라는 매우 정보량이 높은 신호

## 3. 실험 결과

- RECAP으로 학습한 π*0.6은 **모방학습만으로 학습한 기존 π 계열 대비 로버스트니스(robustness)와 처리량(throughput, 시간당 완료 작업 수)이 유의미하게 향상**
- 핵심 주장의 실증: 정책이 **시연 데이터 자체의 품질을 넘어서는** 성능을 보임 — "좋은 행동과 나쁜 행동을 구분하는 법을 배운 뒤, 항상 좋은 쪽을 요청"하는 방식이 실제로 시연 이상의 성능을 만들어낸다는 것을 확인
- 배포 후 수집되는 경험(성공/실패/개입)을 계속 반영하는 **continual improvement** 루프가 실제로 작동함을 실증 — 지금까지의 "한 번 학습, 고정 배포" 패러다임과의 결정적 차이

## 4. 한계 및 Physical AI 전체 지형에서의 위치

- 가치함수 학습 자체의 정확도에 성능이 의존적 — 오프라인 데이터에서 추정한 $V_\phi, Q_\phi$ 가 부정확하면 advantage 조건화도 왜곡될 수 있음
- 여전히 상당한 양의 실제 로봇 경험(on-policy 데이터, 사람의 개입)이 필요 — 순수 시뮬레이션이나 오프라인 데이터만으로는 재현이 제한적일 가능성

**VLA 계열 정리**: RT-1(전용 소형 아키텍처) → RT-2(대형 VLM 재활용) → Octo(모듈형+diffusion, 오픈소스) → OpenVLA(7B 오픈소스 표준) → π0(flow matching, 50Hz) → π0.5(계층적 추론+open-world 일반화) → π*0.6(RL 기반 지속 개선). 이제 이 흐름과 별개로 발전한 **NVIDIA의 휴머노이드 파운데이션 모델 GR00T N1**로 넘어간다.
