## 노트 작성 형식
각 논문 노트는 다음 구조를 따릅니다:
1. 한 줄 요약 / 메타정보
2. 문제의식 (이전 연구의 한계)
3. 아키텍처 (수식 포함)
4. 학습 방법 (손실함수, 데이터, 하이퍼파라미터)
5. 실험 결과
6. 한계 및 다음 논문과의 연결고리
